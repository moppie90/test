# Ruflo helpers

Scripts used by the hooks and status line in `.claude/settings.json`.
Generated by `ruflo init` (3.51.1) and trimmed to what is actually wired up.

| File | Used by |
|------|---------|
| `hook-handler.cjs` | All Claude Code hooks (pre/post Bash and Edit, route, session, compact, subagent, notify) |
| `router.cjs`, `intelligence.cjs`, `memory.cjs`, `session.cjs` | Loaded by `hook-handler.cjs` |
| `auto-memory-hook.mjs` | `SessionStart` (import) and `Stop` (sync) |
| `statusline.cjs` | `statusLine` |
| `ruflo-hook.cjs` | Ruflo mods plugin |
| `helpers.manifest.json` | Signed hashes of the critical helpers, checked by `ruflo doctor` |
| `pre-commit`, `post-commit` | Optional git hooks, see below |

Do not edit the files listed in `helpers.manifest.json`; refresh them with
`npx -y ruflo@3.51.1 init upgrade` instead.

## Optional git hooks

```bash
cp .claude/helpers/pre-commit .git/hooks/pre-commit
cp .claude/helpers/post-commit .git/hooks/post-commit
chmod +x .git/hooks/pre-commit .git/hooks/post-commit
```
